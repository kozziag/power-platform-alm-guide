# Power Platform ALM Guide

A practical, step-by-step guide to Application Lifecycle Management (ALM) for **Power Apps** and **Power Automate**, using Microsoft's current recommended approach: **Solutions** + **Power Platform Pipelines**.

Every step in this guide was tested live end-to-end in a real Power Platform tenant (Development → Test environments) before publishing.

## 📖 View the guide

**👉 [https://kozziag.github.io/power-platform-alm-guide/](https://kozziag.github.io/power-platform-alm-guide/)**

Open that link in any browser — no download or setup needed.

## What's covered

1. Creating a Solution and custom Publisher
2. Building apps/flows inside the solution
3. Setting up a Power Platform Pipeline
4. Deploying from Dev to Test
5. Verifying the deployment
6. Golden rules for keeping ALM healthy
